# 🌙 Карта Веб3 Вселенной ДАО 23m00n

Интерактивная 3D карта Веб3 экосистемы с блокчейном BitMoon в центре и деревьями кватернионов с максимальной энтропией.

## 🎯 Концепция

Карта представляет собой визуализацию Веб3 вселенной, где:

- **Центр энтропии**: Блокчейн BitMoon как точка нулевой энтропии
- **Деревья кватернионов**: Узлы экосистемы с максимальной энтропией
- **Эмиссия энтропии**: Собственная система генерации энтропии
- **Блокчейн данные**: Интеграция с открытыми транзакциями

## 🚀 Возможности

### Визуализация
- 3D интерактивная карта с использованием Three.js
- Анимированные узлы с кватернионной геометрией
- Динамические соединения с центром энтропии
- Реальное время обновления статистики

### Блокчейн Интеграция
- Имитация транзакций BitMoon
- Расчет энтропии на основе типа транзакций
- Эмиссия энтропии каждые 5 секунд
- Влияние интерфейсов на экосистему

### Управление
- Добавление новых узлов
- Управление камерой (мышь + колесико)
- Пауза/продолжение анимации
- Сброс вида

## 🛠 Технологии

- **Three.js** - 3D графика
- **JavaScript ES6+** - Основная логика
- **CSS3** - Стилизация и анимации
- **HTML5** - Структура интерфейса

## 📊 Система Энтропии

### Расчет энтропии
Энтропия рассчитывается на основе:
- Базовой энтропии узла
- Расстояния от центра (BitMoon)
- Временного фактора
- Кватернионных преобразований

### Типы транзакций
- DeFi Swap (0.8)
- NFT Mint (0.9)
- DAO Vote (0.7)
- Staking (0.6)
- Liquidity Provision (0.85)
- Cross-chain Transfer (0.95)
- Oracle Update (0.75)

## 🎮 Управление

### Мышь
- **Перетаскивание**: Вращение камеры
- **Колесико**: Зум

### Кнопки
- **Добавить узел**: Создание нового узла
- **Сброс вида**: Возврат к исходной позиции
- **Пауза/Продолжить**: Остановка/запуск анимации
