# Лунная Река (moonriver)

Библиотека для моделирования резонатора на частоте Шумана, переложенного на формулу сферического солитона и настроенного на размер Луны.

## Возможности
- Расчет частот Шумана для Луны
- Моделирование сферического солитона на сфере
- Класс резонатора, объединяющий оба подхода

## Установка

```bash
pip install .
```

## Пример использования

```python
from moonriver import Resonator

res = Resonator()
freq = res.schumann_frequency(n=1)
profile = res.spherical_soliton_profile(theta=0.5, phi=1.0, t=0)
print(f"Частота Шумана для Луны: {freq} Гц")
print(f"Профиль солитона: {profile}")
```

## Научная справка

**Частоты Шумана** — это резонансные частоты электромагнитных волн между поверхностью планеты и ионосферой. Для Луны расчет ведется по формуле:

\[
f_n = \frac{c}{2\pi R} \sqrt{n(n+1)}
\]

где \(c\) — скорость света, \(R\) — радиус Луны, \(n\) — номер гармоники.

**Сферический солитон** — устойчивое волновое образование на сфере, описываемое, например, гауссовым профилем.
