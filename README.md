# Лунная Река (moonriver)

**moonriver** — научная библиотека для моделирования резонансных явлений, кватернионных интерпретаторов, анализа нейросетей и кибернетических интерфейсов.

---

## Основные возможности

- **Лунный резонатор**: расчет частот Шумана для Луны, моделирование сферических солитонов
- **MoonRiver_Quaternion**: динамический тензор движения нормированной амплитуды (кватернионы)
- **TheMoon_Int**: кватернионный интерпретатор лунного кода с фрактальной структурой
- **SeaResonance (OGL-S)**: моделирование резонанса с учетом волн мирового океана (данные seaman)
- **Neptune DB**: база кватернион-разницы резонанса между морем и Луной, визуализация
- **Anal_NN**: анализатор резонансов нейронных сетей, карта layer0 крупнейших ИИ
- **Виртуальные машины Web3**: карта виртуальных машин с интерфейсами блокчейн/веб3 (разработка)

## Примеры использования

### Лунный резонатор и солитон
```python
from moonriver import Resonator
res = Resonator()
freq = res.schumann_frequency(n=1)
profile = res.spherical_soliton_profile(theta=0.5, phi=1.0, t=0)
```

### Кватернионный тензор
```python
from moonriver import MoonRiver_Quaternion
q = MoonRiver_Quaternion(amplitude=1.0)
tensor = q.dynamic_tensor(t=1.0, omega=2.0, axis=(0, 1, 0))
```

### Интерпретатор лунного кода
```python
from moonriver import TheMoon_Int
interpreter = TheMoon_Int(clock_rate=32, fractal_integrity=0.95)
code = interpreter.interpret(n=1, duration=2.0)
```

### Резонатор с волнами океана
```python
from moonriver import SeaResonance
sea_res = SeaResonance()
t_arr, signal = sea_res.sea_resonance_signal(n=1, duration=3600, sample_rate=1.0)
```

### Анализ нейросетей и карта layer0
```python
from anal_nn import Anal_NN
ann = Anal_NN()
ann.plot_resonance_map()
```

## Научная справка

- **Частоты Шумана**: резонансные частоты электромагнитных волн между поверхностью планеты и ионосферой. Для Луны:
  \[
  f_n = \frac{c}{2\pi R} \sqrt{n(n+1)}
  \]
- **Сферический солитон**: устойчивое волновое образование на сфере, например, гауссов профиль.
- **Кватернионы**: используются для описания вращения и динамики в резонансных моделях.
- **Фрактальный код**: структура, повторяющаяся на разных масштабах, используется в TheMoon_Int.
- **OGL-S**: резонатор с учетом влияния волн мирового океана.
- **Neptune DB**: база кватернион-разницы между морским и лунным резонансом.
- **Anal_NN**: анализатор layer0 резонансов крупнейших нейросетей (GPT, Llama, Gemini и др.).
- **Web3/VM карта**: (в разработке) — визуализация виртуальных машин с интерфейсами блокчейн/веб3 и их кибернетических резонансов.
