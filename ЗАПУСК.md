# 🚀 Инструкции по запуску карты Веб3 Вселенной ДАО 23m00n

## Быстрый запуск

### Способ 1: Автоматический скрипт
```bash
./start-server.sh
```

### Способ 2: Ручной запуск
```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

## 📱 Доступ к приложению

После запуска сервера откройте браузер и перейдите по адресу:

**Локальный доступ:**
```
http://localhost:8000
```

**Доступ с других устройств:**
```
http://[IP-адрес-компьютера]:8000
```

## 🔧 Требования

- Python 3.x
- Современный браузер (Chrome, Firefox, Safari, Edge)
- Интернет-соединение (для загрузки Three.js и API)

## 🎮 Использование

1. **Откройте браузер** и перейдите по адресу `http://localhost:8000`
2. **Дождитесь загрузки** 3D сцены
3. **Нажмите кнопку** "🌙 Загрузить реальные данные"
4. **Используйте мышь** для навигации:
   - Перетаскивание: вращение камеры
   - Колесико: зум
5. **Нажимайте кнопки** для управления:
   - "Добавить узел": создание нового узла
   - "Сброс вида": возврат к исходной позиции
   - "Пауза/Продолжить": остановка/запуск анимации

## 🌐 Возможные проблемы

### Проблема: "Сервер недоступен"
**Решение:**
```bash
# Проверьте, что сервер запущен
ps aux | grep "python3 -m http.server"

# Если не запущен, запустите заново
./start-server.sh
```

### Проблема: "Файлы не загружаются"
**Решение:**
```bash
# Проверьте, что все файлы на месте
ls -la *.html *.css *.js

# Перезапустите сервер
pkill -f "python3 -m http.server"
./start-server.sh
```

### Проблема: "CORS ошибки"
**Решение:**
- Используйте Firefox (менее строгие CORS правила)
- Или запустите Chrome с флагом:
  ```bash
  google-chrome --allow-file-access-from-files
  ```
